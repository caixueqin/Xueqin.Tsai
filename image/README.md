# MathCraft image assets

- `source-atlases/`: original mineral card sheets used by the split script.
- `cards/`: generated 64-card artwork set and `manifest.json`.
- `frames/`: suit frame artwork.
- `user-icons/`: child avatar expressions.
- `draw-assets/`: rock-choice, broken-rock, tool, and PSD source assets.

Generate the card artwork with:

```bash
python3 scripts/split_mineral_cards.py
```
